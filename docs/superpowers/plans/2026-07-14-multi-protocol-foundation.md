# Multi-Protocol Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lay the load-bearing foundation for turning `hihy` into a multi-protocol installer: a modular build system, an "active protocol/core" state model, sing-box core download, and install-state/recovery awareness of sing-box artifacts — all without touching the working Hysteria2 behavior.

**Architecture:** Dual-core (`apernet/hysteria` keeps serving Hysteria2; `sing-box` will serve VLESS/VMess/Trojan in later plans). One active protocol per machine, recorded in an `active` state file that every lifecycle command will dispatch on. Source is split into `server/src/*.sh` modules concatenated by `server/build.sh` into the single distributed `server/hy2.sh`; distribution/self-update/launcher mechanisms are unchanged.

**Tech Stack:** Pure Bash. No framework. Tests are standalone harnesses that `source` the built `hy2.sh` and redirect filesystem side effects via `HIHY_*` env vars and mock commands on `PATH`.

## Global Constraints

- **`server/hy2.sh` is a BUILD ARTIFACT after Task 1.** Never hand-edit it. Edit files under `server/src/` and run `bash server/build.sh` to regenerate it. Commit both the changed `src/` file and the regenerated `hy2.sh`.
- **`hihyV` must remain on line 2 of the built `hy2.sh`** — older installed copies parse the remote script with `sed -n '2p'`. So `server/src/00-header.sh` starts with the shebang (line 1) then `hihyV=` (line 2).
- **Single-file distribution is unchanged.** `install.sh`, the self-update flow, and the `/usr/bin/hihy` launcher all still fetch/copy exactly one file (`hy2.sh`). Do not add runtime `source` of external files.
- **User-facing strings stay Chinese; comments and identifiers stay English.**
- **This code runs on Linux production servers; only the test scripts run on the macOS dev machine.** Do NOT run `install`/`uninstall`/lifecycle on the dev machine.
- **New filesystem paths and shelled-out binaries must be read from `HIHY_*` variables** (`${HIHY_X:-/default}` pattern) so tests can redirect them.
- **Single active protocol per machine** (reinstall overwrites). No multi-protocol coexistence.
- **Pinned sing-box version:** default `HIHY_SINGBOX_VERSION=v1.13.14` (real release; user-overridable). Release-tag has a leading `v`; the tarball filename drops it: `sing-box-1.13.14-linux-<arch>.tar.gz`.

```bash
# ---------------------------------------------------------------------------
# Active-protocol state model (multi-protocol foundation)
#
# A hihy install runs exactly one protocol at a time. The `active` file records
# which protocol/core is installed so every lifecycle command can dispatch to
# the right core. Existing Hysteria2-only installs predate this file, so the
# getters fall back to detecting the legacy config.yaml and reporting hysteria.
# ---------------------------------------------------------------------------
HIHY_ACTIVE_FILE="${HIHY_ACTIVE_FILE:-$HIHY_ROOT_DIR/active}"
HIHY_SYSCTL_FILE="${HIHY_SYSCTL_FILE:-/etc/sysctl.d/99-hihy.conf}"

writeActiveState() {
    # Args: one or more key=value pairs, e.g. writeActiveState "protocol=vless" "core=sing-box"
    local active_file="$HIHY_ACTIVE_FILE"
    local old_umask
    old_umask=$(umask)
    umask 077
    mkdir -p "$(dirname "$active_file")"
    : > "$active_file"
    local pair
    for pair in "$@"; do
        printf '%s\n' "$pair" >> "$active_file"
    done
    umask "$old_umask"
}

getActiveValue() {
    # Args: $1 key, $2 optional active-file path (defaults to $HIHY_ACTIVE_FILE).
    local key="$1"
    local active_file="${2:-$HIHY_ACTIVE_FILE}"
    [ -f "$active_file" ] || return 0
    grep -m1 "^${key}=" "$active_file" | cut -d '=' -f 2-
}

getActiveCore() {
    # Optional $1: active-file override. Echoes hysteria | sing-box | "".
    local active_file="${1:-$HIHY_ACTIVE_FILE}"
    local core
    core=$(getActiveValue "core" "$active_file")
    if [ -n "$core" ]; then
        printf '%s' "$core"
        return 0
    fi
    # Back-compat: legacy Hysteria2-only install has no active file.
    if [ -f "$HIHY_ROOT_DIR/conf/config.yaml" ]; then
        printf 'hysteria'
        return 0
    fi
    printf ''
}

getActiveProtocol() {
    # Optional $1: active-file override. Echoes hysteria2 | vless | vmess | trojan | "".
    local active_file="${1:-$HIHY_ACTIVE_FILE}"
    local proto
    proto=$(getActiveValue "protocol" "$active_file")
    if [ -n "$proto" ]; then
        printf '%s' "$proto"
        return 0
    fi
    if [ -f "$HIHY_ROOT_DIR/conf/config.yaml" ]; then
        printf 'hysteria2'
        return 0
    fi
    printf ''
}
```

```bash
# ---------------------------------------------------------------------------
# sing-box core management (multi-protocol foundation)
#
# sing-box serves VLESS/VMess/Trojan (later plans). Releases ship a per-arch
# tar.gz (no checksums file), so this mirrors downloadHysteriaCore: HTTPS
# download + non-empty/runnable check, plus a tar extraction. The version is
# pinned for reproducible configs; override via HIHY_SINGBOX_VERSION.
# ---------------------------------------------------------------------------
HIHY_SINGBOX_VERSION="${HIHY_SINGBOX_VERSION:-v1.13.14}"
HIHY_SINGBOX_BASE_URL="${HIHY_SINGBOX_BASE_URL:-https://github.com/SagerNet/sing-box/releases/download}"
HIHY_SINGBOX_BIN="${HIHY_SINGBOX_BIN:-$HIHY_ROOT_DIR/bin/sing-box}"

getSingboxArch() {
    # Maps `uname -m` (or $1) to a sing-box release arch token.
    local machine="${1:-$(uname -m)}"
    case "$machine" in
        x86_64|amd64)        printf 'amd64' ;;
        aarch64|arm64)       printf 'arm64' ;;
        armv7l|armv7|armhf)  printf 'armv7' ;;
        i686|i386)           printf '386' ;;
        s390x)               printf 's390x' ;;
        ppc64le)             printf 'ppc64le' ;;
        loongarch64|loong64) printf 'loong64' ;;
        *) return 1 ;;
    esac
}

getLatestSingboxVersion() {
    local headers
    headers=$(fetchRemoteHeadersFromSources "https://github.com/SagerNet/sing-box/releases/latest") || return 1
    printf '%s\n' "$headers" | grep -i '^location:' | grep -o 'tag/[^[:space:]]*' | sed 's/tag\///;s/\r//;s/ //g' | head -n 1
}

downloadSingboxCore() {
    local version="$HIHY_SINGBOX_VERSION"
    local arch
    if ! arch=$(getSingboxArch); then
        echoColor red "Error[OS Message]: 不支持的架构 $(uname -m),无法下载 sing-box"
        return 1
    fi

    local ver_no_v="${version#v}"
    local dir_name="sing-box-${ver_no_v}-linux-${arch}"
    local file_name="${dir_name}.tar.gz"
    local url="${HIHY_SINGBOX_BASE_URL%/}/${version}/${file_name}"

    echoColor purple "正在下载 sing-box ${version} (${arch})..."

    local tmp_tar tmp_dir
    tmp_tar=$(mktemp) || return 1
    tmp_dir=$(mktemp -d) || { rm -f "$tmp_tar"; return 1; }

    if ! downloadToFile "$url" "$tmp_tar" || [ ! -s "$tmp_tar" ]; then
        rm -rf "$tmp_tar" "$tmp_dir"
        echoColor red "下载 sing-box 失败:网络错误或返回内容为空"
        return 1
    fi

    if ! tar -xzf "$tmp_tar" -C "$tmp_dir" >/dev/null 2>&1; then
        rm -rf "$tmp_tar" "$tmp_dir"
        echoColor red "解压 sing-box 失败"
        return 1
    fi

    local extracted="$tmp_dir/${dir_name}/sing-box"
    if [ ! -f "$extracted" ]; then
        rm -rf "$tmp_tar" "$tmp_dir"
        echoColor red "sing-box 压缩包结构异常,未找到二进制"
        return 1
    fi

    mkdir -p "$(dirname "$HIHY_SINGBOX_BIN")"
```
